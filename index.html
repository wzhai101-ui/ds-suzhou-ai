What is Agentic AI?

AI systems that can plan and execute multistep workflows with limited human direction.

They reason, interact with enterprise systems, coordinate with other agents, and autonomously adjust their actions as context evolves.

The strategic shift

Agents move from passive assistance to active execution, creating a new layer between people, processes, and fragmented legacy systems.

Latest developments

The report's central story: Agentic AI is moving from demos and point tools into the operating layer of the enterprise.

01 · Enterprise orchestration

Process orchestration is becoming the product

Companies are investing in agentic layers that span ERP, CRM, and supply chain systems. The strategic value comes from coordinating work across systems, not from adding another isolated assistant.

02 · Middleware

Multiagent teams are the new enterprise middleware

A manager agent can route subtasks to specialized agents. Frameworks such as LangGraph and CrewAI are helping multiagent systems move from demos toward production.

03 · Integration

Legacy systems are the bottleneck

The hard part is turning model outputs into safe action through APIs and legacy ERP systems. Machine-readable interfaces and integration standards become strategic.

04 · Economics

Token economics becomes an operating metric

Agentic workflows can require far more compute than chatbots. Leaders must track token throughput, cost per task, inference efficiency, and orchestration overhead.

05 · Security

Agents create a new identity layer

Read/write agents introduce nonhuman identities - API keys, service accounts, and machine credentials - that need registration, access control, monitoring, and containment.

06 · Workflow adoption

Agents are entering core business workflows

Adoption is shifting from stand-alone applications to embedded execution in customer operations, productivity, software development, and emerging agentic commerce.

How the agentic loop works

Agentic systems turn an intent into an adaptive workflow, rather than stopping at a single generated response.

01

Understand the goal

Interpret intent, context, constraints, and the desired outcome.

02

Plan the work

Break the objective into tasks and choose tools, data sources, or specialized agents.

03

Act across systems

Interact with enterprise software, APIs, databases, and other agents.

04

Evaluate & adapt

Check results, respond to new context, and adjust the next action.

The value comes from redesigning workflows around human-agent collaboration - not simply placing an agent on top of an unchanged process.

Where enterprise value is emerging

  • Process orchestration across ERP, CRM, supply chain, and productivity systems
  • Multiagent “teams” that route subtasks to specialized agents
  • Active execution inside enterprise workflows, not stand-alone chat interfaces
  • Legacy-system connective tissue that can help extract more ROI from existing tech spend

What has to change underneath

  • Orchestration layers become a new form of enterprise middleware
  • APIs and machine-readable interfaces become critical for safe action
  • Nonhuman identities - API keys, service accounts, machine credentials - need governance
  • Token usage, inference efficiency, and workflow economics become operating metrics

Adoption is real - scale is not

McKinsey scores Agentic AI at 3 out of 5: piloting. Many organizations are testing targeted deployments, while relatively few have fully scaled an agentic operating model.

The three questions leaders cannot avoid

Can we trust the action?

Reliability, evaluation, observability, human escalation, and accountability need to be designed into the workflow.

Can we afford the loop?

Agentic systems can consume far more compute and tokens than chatbots; cost discipline must sit beside model capability.

Can we secure the identity?

Agents that read and write across systems create new attack surfaces, requiring registration, access control, monitoring, and containment.
